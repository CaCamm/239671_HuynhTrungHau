## 2. MÔ TẢ NGẮN GỌN HỆ THỐNG QUẢN LÝ NHÂN SỰ
Hệ thống quản lý nhân sự trên nền tảng đám mây hỗ trợ quản lý hồ sơ nhân viên với các chức năng chính:
- Hiển thị danh sách nhân viên.
- Xem chi tiết hồ sơ nhân viên.
- Thêm mới hồ sơ nhân viên.
- Tìm kiếm nhân viên theo mã nhân viên hoặc họ tên.
- Cập nhật thông tin hồ sơ nhân viên.
- Xóa hồ sơ nhân viên (có xác nhận trước khi xóa).
